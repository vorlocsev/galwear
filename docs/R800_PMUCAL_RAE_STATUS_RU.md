# SM-R800 — RAE status read (NON-RELEASE)

База Linux 4.19: 50db73fc799f20a7120a8b5f653b16cc123d856f.
Ветка наследует PMUCAL status guard и rollback доменов.

Проверены flexpmu_cal_local_exynos9110.h и flexpmu_cal_p2vmap_exynos9110.h:
Linux-таблицы DISPAUD, G3D, IS, MFCMSCL и VTS используют один
безусловный PMUCAL_READ, ненулевую маску и отображённую PMU base
0x11860000. CHUB-таблица также содержит обычное чтение; её семантика
и non-Linux окружение отдельно не подтверждены.

Новый pmucal_rae_read_status принимает только обычные чтения, проверяет
всю таблицу до MMIO: непустой массив, тип, маску, PA/VA, выравнивание
и границу 64 KiB. Не изменяет seq->value и не использует сохранённые
значения. Условные чтения и записи в status sequence отклоняются.
Семантика сравнения с mask сохранена. Общие RAE sequences не изменены.

Три секции diff реконструированы из точной базы с проверкой контекста.
Добавлен host C unittest, извлекающий новую функцию непосредственно
из патча и компилирующий с fake MMIO; эквивалентный локальный C harness
с той же функцией прошёл cc -Wall -Wextra -Werror и assertions:
пустой ввод, off/on, устаревший value, условное чтение, NULL VA,
нулевой PA, невыровненный/вне диапазона offset, последний допустимый
регистр, нулевая маска. Обновлён предыдущий статический тест.
Запуск полного репозиторного unittest и CI не подтверждён.

Ограничения: проверка ненулевого VA не гарантирует доступность
физического устройства, raw MMIO может вызвать bus fault;
не доказаны корректность всех SoC, атомарность нескольких чтений,
семантика промежуточных состояний питания. Для SM-R800 deep sleep
по-прежнему выключен. Следующий этап: abort между syscore и PSCI
и stale need_restore/need_skip в save/restore. safe_to_flash=false.
Только форк, без PR, без изменения main/upstream.
