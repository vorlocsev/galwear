# SM-R800 — HWC2On1Adapter layer ABI (NON-RELEASE)

Убрано угадывание stride по чтению последнего элемента при двух
размерах структуры. Оно могло читать вне выделенного массива и
менять выбранный ABI между prepare и set.

При open выбирается одна раскладка:
- debug.r800.layer_stride пусто или 100: исторический Samsung J4 donor.
- 96: явный AOSP ARM32.
- другое значение: отказ открытия HAL.
Изменение property не действует до следующего открытия устройства.

Компилятор проверяет ARM32, sizeof(hwc_layer_1_t)=96, handle offset 12,
acquire offset 64, release offset 68, display hwLayers offset 20.
Primary list должен содержать ровно один FB_TARGET в последней
позиции (кроме пустого списка); число слоёв ограничено 256,
дисплеев — 3. prepare очищает прежнее overlay selection; set
проверяет индексы и типы overlay перед использованием.

Восемь тестов: host C fixtures для обеих раскладок, invalid property,
отсутствующего/двойного FB target, превышения count, статические
проверки. Интеграционный CI обновлён, его результат не подтверждён.

Ограничения: бинарник donor adapter отсутствует; 100 байт и совпадение
префикса с AOSP остаются историческим предположением, не подтверждённым
измерением. У HAL нет длины allocation; даже фиксированный stride
не гарантирует bounds при неверно выбранном ABI. При отклонении
несовместимого списка set возвращает EINVAL без закрытия подозрительных
FD: реакция adapter и возможная утечка при этом требуют проверки.
HWC2On1Adapter, virtual display, реальные fence ownership и zero-copy
не испытаны. Не считать эти изменения разрешением на прошивку.

Следующий шаг: exact-head CI, проверка donor ELF/disassembly при
наличии законно полученного образа и интеграционная сборка.
Main/upstream/PR/firmware/реальные часы не затронуты.
