# SM-R800 — Sensor HAL: SSP mask and evdev recovery

Изменения в src/hal/sensors_r800.c:
- Ошибка чтения, пустая или некорректная десятичная маска SSP больше не
  интерпретируются как ноль. Запись блокируется; сохраняются чужие биты.
- Короткая запись sysfs возвращает ошибку, локальный enabled откатывается.
- Читается один input_event за раз, поэтому заполнение выходного
  массива Android не уничтожает остаток уже прочитанного пакета.
- После SYN_DROPPED частичный кадр очищается, данные отбрасываются
  до следующего SYN_REPORT.
- Ошибки poll, EOF и неполные записи input_event не игнорируются.
- При неудачной начальной записи маски открытые дескрипторы закрываются.

Восемь тестов: два набора входных значений для фактического C-парсера,
C-проверка SYN_DROPPED и пять статических проверок защитных условий.
CI компилирует извлечённые функции с host cc, не весь Android HAL.

Ограничения: read-modify-write SSP не атомарен относительно внешнего
Tizen sensord, поэтому конкурентная запись остаётся возможной.
Откат локального enabled не гарантирует откат аппаратного состояния.
Планировщик HR при отказах, FIFO контекстных датчиков, восстановление
после отключения evdev и корректность flush требуют отдельной работы.
Чтение по одному событию может повысить количество системных вызовов;
производительность не измерялась. Физическая точность датчиков,
пульсометр и Wear Health Services не проверены. NON-RELEASE.
Main, upstream и реальные часы не изменяются.
