# SM-R800 — GNSS HAL and bridge recovery (NON-RELEASE)

Изменены src/hal/gps_r800.c и src/tools/gps/gpsbridge.c.

HAL проверяет конечность и диапазоны числовых полей FIX, timestamp,
битовую маску, NMEA checksum, размер и завершённость записей.
Данные вне запрошенной сессии игнорируются (проверка состояния не
является барьером для уже выполняющегося callback).
Спутниковые поля инициализируются даже при неполной записи;
индексы used расширены для SBAS/QZSS, не выводится фиктивный
флаг almanac на основании угла спутника. Эпоха очищается при reconnect.

В обоих процессах отправка MSG_NOSIGNAL исключает SIGPIPE от сокета;
ошибка приводит к shutdown, а close остаётся за читающим потоком.
HAL обрабатывает частичные send; bridge закрывает сессию при
частичной отправке, не блокируя callback. Ошибки инъекции времени
и координат в HAL возвращаются вызывающему коду.
Bridge проверяет snprintf перед отправкой FIX, ошибки init/start/stop,
не помечает неудачный START как активный. Новый файл last fix
создаётся с mode 0600 (старые файлы автоматически не мигрируют).

Восемь host-тестов: компиляция фактических C-функций разбора,
проверка диапазонов и checksum, статические проверки сокетов.
Не является полной сборкой NDK или Tizen ARM/glibc.

Ограничения: совместимость с реальными NMEA и необязательными
полями FIX ещё не проверена; строгая валидация может отбросить
реальное сообщение. GSV/GSA не прошли полную проверку семантики.
Cleanup/lifetime callbacks, синхронизация cache, аутентификация
локального сокета, проверка входящих TIME/LOC в bridge, доверенность
LTO и точность координат остаются открытыми. CI не подтверждён.
Main, upstream, PR и реальные часы не затронуты.
