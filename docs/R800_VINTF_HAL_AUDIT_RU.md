# SM-R800 — аудит VINTF и HAL (NON-RELEASE)

Работа только в форке vorlocsev/galwear. Не требуется запуск Android,
монтирование разделов, изменение образов или подключение часов.

## Офлайн-проверка

```sh
python3 build/r800_vintf_hal_audit.py \
  --root /path/to/extracted-android-root \
  --output /tmp/r800-vintf.json
```

Требуется заранее извлечённое неизменяемое дерево с system/vendor и,
при наличии, product, system_ext, odm. Проверяются VINTF XML и фрагменты
manifest, включая устаревшие расположения. Отчёт пишется вне дерева.
Поддерживаются HIDL/AIDL, конкретные instance, fqname и буквальные
диапазоны версий. DTD и объявления XML entities запрещены.

Матрицы рассматриваются отдельно: обязательные и необязательные HAL,
уровни FCM, найденные декларации и отсутствующие кандидаты видны в JSON.
Результат LITERAL_CANDIDATES_ONLY означает только наличие деклараций,
а не успешное прохождение Android VINTF. REVIEW_REQUIRED требует
разбора; он не равнозначен доказанной несовместимости.

Не реализованы: выбор активного FCM и SKU, правила merge/override,
семантика совместимости минорных HIDL версий, regex-instance,
условия kernel/sepolicy, полная схема VINTF, проверки подписи APEX,
реальные Binder-сервисы. Для официальной проверки нужен Android
checkvintf/libvintf соответствующей версии с корректными входными
параметрами. Не использовать этот отчёт для допуска к прошивке.

## Связь с существующим портом

payload/start.sh исторически подставляет следующие библиотеки:
- hwcomposer.r800.so
- sensors.r800.so
- audio.primary.r800.so
- gps.r800.so

Это имена legacy HAL-модулей, а не доказательство регистрации
соответствующих HIDL/AIDL интерфейсов. Следующий этап: сопоставление
VINTF деклараций с init rc, сервисами и ELF-зависимостями этих модулей.

CI использует только синтетические XML/ELF fixtures. Реальные
донорские образы не скачиваются и не публикуются. При любом результате
safe_to_flash=false.
