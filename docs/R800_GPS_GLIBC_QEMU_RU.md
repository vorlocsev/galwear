# R800: изолированный glibc smoke test

Требуются Linux, обычный непривилегированный пользователь, bubblewrap,
qemu-arm-static, Python 3, NDK r27c и четыре проверенные библиотеки из
одного образа Tizen 2.24 (профиль gps-glibc). Не использовать случайные
донорские файлы: SHA-256 не доказывает их подлинность.

```sh
sh build/r800_gps_glibc_qemu.sh /path/to/ndk-r27c /path/to/gps-donor/tizen
```

Сценарий компилирует собственную ARM32 пробу и маленькую DSO, проверяет
статический контракт, затем запускает только пробу через QEMU user-mode
в отдельном read-only корне без сети и доступа к исходному образу.
Если sandbox недоступен, тест прекращается; запуск без изоляции не предусмотрен.

Критерии: точная версия glibc 2.24, начальное значение TLS и независимость
TLS в pthread, join, dlopen/dlsym/dlclose, код возврата 0, неизменность
хешей. Вывод QEMU_USER_ONLY=PASS не является доказательством запуска
на ядре R800, работы libbrcm.so, Android HAL или GNSS.
Проверка не создаёт прошивку. safe_to_flash=false.

Статус: сценарий подготовлен; запуск с оригинальным донором не подтверждён.
